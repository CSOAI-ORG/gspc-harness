# How CSOAI's evidence trail holds up in court

CSOAI's signed receipts, content-addressing, witnesses, and corrections feed are designed to survive legal challenge. Here's how each piece of evidence holds up in court.

## Why this matters

When a regulator, buyer, or counterparty sues, the question is: "Is this evidence admissible, authentic, and tamper-evident?"

CSOAI's evidence trail is designed for that question. Each component has a clear legal-grade property.

## Component 1: Signed receipt

**Property:** Ed25519 signature against a published key.

**Court test:** Is the signature authentic? Did the named signer actually produce it?

**CSOAI answer:**
- The key is published at `csoai.org/.well-known/did.json` (a public DID document)
- The signature can be verified by anyone with the public key
- The verifier at `councilof.ai/gspc-verify` performs the check in-browser
- The signing key is in an HSM; the operator cannot forge signatures without going through the HSM

**Admissibility:** Ed25519 is well-established cryptographic standard. Courts in major jurisdictions accept Ed25519 signatures as authentic.

## Component 2: Content-addressing

**Property:** SHA-256 hash of the canonical JSON body.

**Court test:** Has the content changed since it was signed?

**CSOAI answer:**
- The hash is in the receipt itself
- Any change to the content changes the hash
- Anyone can recompute the hash and compare
- JCS canonicalisation ensures the same logical content produces the same hash

**Admissibility:** SHA-256 is a cryptographic hash standard. JCS is a JSON canonicalisation standard (RFC 8785). Courts accept hash-based integrity proofs.

## Component 3: Public Merkle root tree

**Property:** Card inclusion in the public Merkle tree, with the root hash anchored in three independent systems.

**Court test:** Did this card exist at the time claimed?

**CSOAI answer:**
- The card is in the Merkle tree
- The Merkle root is published at `councilof.ai/root.json`
- The Merkle root is anchored in:
  1. CSOAI's website (current root)
  2. Sigstore Rekor (log index, body hash)
  3. Bitcoin blockchain (via OpenTimestamps)

**Admissibility:** Triple anchoring provides overwhelming evidence of the card's existence at the claimed time. A court would need to invalidate Rekor + Bitcoin to dispute the timestamp.

## Component 4: Corrections feed

**Property:** Machine-derived log of every correction.

**Court test:** Did the measurer cover up errors?

**CSOAI answer:**
- The feed is generated by the same pipeline that produces measurements
- No human edits the feed
- The feed is signed and public
- Every entry references old and new cards

**Admissibility:** A corrections feed that's machine-derived and signed is far more credible than a manually-maintained "errata" page. Courts recognise the difference.

## Component 5: Methodology and items

**Property:** Full source code in versioned Git repository.

**Court test:** Was the methodology appropriate?

**CSOAI answer:**
- Source code is in `github.com/CSOAI-ORG/gspc-harness`
- Git history preserves every change
- Items are versioned and content-addressed
- The methodology is documented in code, not policy

**Admissibility:** Source code is inspectable. The court (or an expert witness) can read the actual code and verify the methodology.

## What a court challenge would look like

A court challenge to CSOAI's evidence would proceed:

1. **Plaintiff:** "This measurement is wrong."
2. **CSOAI:** "Here's the signed receipt. Here's the verifier. Verify it yourself."
3. **Court:** Verifies the signature, content hash, and Merkle inclusion.
4. **Plaintiff:** "But the methodology was inappropriate."
5. **CSOAI:** "Here's the source code. Here's the methodology version. Here's the items."
6. **Court:** Reviews the methodology, possibly with an expert witness.
7. **Plaintiff:** "But you got it wrong on a previous measurement."
8. **CSOAI:** "Here's the corrections feed. We caught it ourselves and published the correction."

CSOAI's evidence trail is designed to survive this sequence.

## The bottom line

CSOAI's evidence trail is designed for legal challenge. Each component has a clear chain-of-custody guarantee.
