How to Cite CSOAI GSPC

When referencing CSOAI's measurement framework in academic papers, regulatory filings, reports, or media, please use the formats below. All citations should include the version, date, and verification URL.

1. Citing the GSPC board (overall framework)

APA

CSOAI Ltd. (2026). GSPC: Governance, Safety, Provenance, Continuity — A22-axis AI measurement framework (Version 1.0). https://councilof.ai/api/gspc

BibTeX

@misc{csoai_gspc_2026,
  author = {{CSOAI Ltd}},
  title = {GSPC: Governance, Safety, Provenance, Continuity — A 22-axis AI measurement framework},
  year = {2026},
  version = {1.0},
  url = {https://councilof.ai/api/gspc},
  note = {Accessed: \today}
}

Zenodo DOI

DOI: 10.5281/zenodo.21991104

Citation: CSOAI Ltd. (2026). GSPC Measurement Framework (Version 1.0). Zenodo. https://doi.org/10.5281/zenodo.21991104

2. Citing a specific card

APA

CSOAI Ltd. (2026). GSPC measurement card: [SUBJECT_NAME] (Card ID: [CARD_ID]). https://councilof.ai/gspc-verify?card=[CARD_ID]

BibTeX

@misc{csoai_card_[CARD_ID],
  author = {{CSOAI Ltd}},
  title = {GSPC measurement card: [SUBJECT_NAME]},
  year = {2026},
  howpublished = {Card ID: [CARD_ID]},
  url = {https://councilof.ai/gspc-verify?card=[CARD_ID]},
  note = {Content-addressed: sha256=[CONTENT_ID]}
}

3. Citing the public root

APA

CSOAI Ltd. (2026). GSPC public root (Root SHA-256: [ROOT_SHA]). https://councilof.ai/root.json

BibTeX

@misc{csoai_root_2026,
  author = {{CSOAI Ltd}},
  title = {GSPC public root},
  year = {2026},
  howpublished = {Root SHA-256: [ROOT_SHA]},
  url = {https://councilof.ai/root.json},
  note = {Rekor log index: [REKOR_INDEX]; OTS: confirmed in Bitcoin block [BLOCK]}
}

4. Citing a correction

APA

CSOAI Ltd. (2026). Correction: [CORRECTION_TITLE] (Correction ID: [C_ID]). https://councilof.ai/feeds/corrections.xml

5. Verification

Every citation can be independently verified:

  • Card verification: councilof.ai/gspc-verify — paste card ID, recomputes SHA-256 and checks Ed25519 signature.
  • Root verification: councilof.ai/root.json — Merkle root, card count, as_of timestamp.
  • Correction feed: councilof.ai/feeds/corrections.xml — machine-derived corrections ledger.
  • Rekor transparency log: Search by log index at search.sigstore.dev.
