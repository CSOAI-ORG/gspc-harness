How x402 Payment Works

Example HTTP 402 challenge returned when you call a metered tool without payment

HTTP Response — csoai.proof.generate
HTTP/1.1 402 Payment Required
{
  "x402Version": 1,
  "accepts": [
    {
      "scheme": "exact",
      "network": "base",
      "maxAmountRequired": "10000",       // 0.01 USDC (6 decimals)
      "resource": "https://api.councilof.ai/mcp/csoai.proof.generate",
      "description": "Generate a cryptographic safety proof",
      "payTo": "0x742d35Cc6634C0532925a3b844Bc9e7595f2bD18",
      "asset": "0x833589fCD6eDb6E08f4c7C32D4f71b54bdA02913",  // USDC on Base
      "extra": {
        "sku": "CSOAI-TOOL-PROOF-401"
      }
    }
  ]
}
Flow: Your MCP client receives this 402 challenge, signs a Base mainnet USDC transfer for $0.01 to the payTo address, and retries the request with the payment proof in the X-Payment header. CSOAI verifies the on-chain transaction and returns your proof. No API keys, no accounts, no subscriptions — just a micropayment per call.

Notes

Why "corrections free forever"?
If a CSOAI proof contains an error, we want it fixed — not buried. Submitting a correction to any existing proof is always free, regardless of whether the original proof was free or paid. Corrections are cryptographically linked to the original proof and create an immutable audit trail.

Why Base mainnet USDC?
Base provides sub-cent transaction fees with Ethereum L1 security. USDC is a regulated, dollar-backed stablecoin — $0.01 means exactly one cent, every time. No volatile tokens, no gas fee surprises.

No subscriptions or minimums.
Pay per call, only when you generate value. Free tools will remain free. x402 pricing is fixed at $0.01 USDC per call with no volume discounts — the price is already as low as practical for cryptographic proof generation.
