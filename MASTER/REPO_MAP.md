# REPO MAP — branches, remotes, and where this master lives

Two branches. Don't get them mixed up. The lane work lives on
`hermes/inspect-register-readiness`. The upstream public ledger lives on
`main` and is owned by other agents, not by this lane.

## Remotes

```
origin   https://github.com/CSOAI-ORG/gspc-harness.git
```

## Branches

| branch | who owns it | what it carries |
|---|---|---|
| `main` | M4 + Maple (other agents) | the public ledger: 305 leaves, ingest/release of card admissions |
| `hermes/inspect-register-readiness` | M2 / Hermes (this lane) | the master at `MASTER/`, the OTS stamps, the operational scripts |

## What lives where

The **master** (`MASTER/`) is on `hermes/inspect-register-readiness` only.
It is NOT on `main`. When you `git log --all --oneline MASTER/`, every
commit shown is from this lane, not from upstream.

The **public signed root** (`councilof.ai/root.json`, 305 leaves) is
generated by `main`. The M2 lane does not commit to `main`. If you want
the master promoted upstream, it goes through M4's release pipeline —
this lane does not push to `main`.

## Golden rule

Before any commit on this lane:

```bash
git branch --show-current
# must print: hermes/inspect-register-readiness
```

If it prints anything else (especially `main`), `git checkout
hermes/inspect-register-readiness` first. The `tools/branch_sync.sh`
script automates this check.
