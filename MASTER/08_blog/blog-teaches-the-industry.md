# What CSOAI's evidence trail teaches the AI governance industry

CSOAI's evidence trail — open methodology, signed receipts, content-addressing, public verifier, corrections ledger — is a model for AI governance infrastructure.

## The pattern

CSOAI's evidence trail pattern is:

1. **Open methodology** as code
2. **Signed receipts** for every measurement
3. **Content-addressing** of every artifact
4. **Independent witnessing** in external systems (Rekor + OTS)
5. **Public verifier** for everyone
6. **Machine-derived corrections** for errors

Any AI governance organisation can adopt this pattern. Here's the playbook.

## Component 1: Open methodology

Publish your scoring methodology as code, not narrative:

- Use Git for version control
- Use tests to enforce the rules
- Use CI to block releases that violate the rules
- License under Apache-2.0 for maximum compatibility

The methodology is the most important thing you produce. It must be inspectable.

## Component 2: Signed receipts

Every measurement produces a signed artifact:

- Pick a signing algorithm (Ed25519 is recommended)
- Generate a key pair
- Store the private key in an HSM
- Publish the public key in a DID document
- Sign every measurement output
- Include the signature in the receipt

The signature is what makes the measurement authoritative.

## Component 3: Content-addressing

Every artifact gets a content hash:

- Use SHA-256 for compatibility
- Use JCS for canonical JSON serialisation
- Include the content hash in the signature payload
- Verify the hash on every read

Content-addressing is what makes tampering detectable.

## Component 4: Independent witnessing

Anchor your receipts in external systems:

- Sigstore Rekor for transparency logs
- OpenTimestamps for Bitcoin anchoring
- Public Merkle tree for compact proofs
- Multiple witnesses for redundancy

Independent witnesses are what make your evidence trail trustworthy.

## Component 5: Public verifier

Anyone can verify any artifact:

- Build a browser-based verifier (no server-side trust)
- Recompute the content hash
- Verify the signature
- Verify the Merkle inclusion
- Report VALID / INVALID / UNCHECKABLE

The verifier is the proof that the system works as claimed.

## Component 6: Machine-derived corrections

Errors are logged automatically:

- When a measurement is corrected, generate a new card
- The corrections feed is generated by the same pipeline
- Old cards stay in the root tree
- Supersessions are explicit

Machine-derived corrections are the operational proof of honesty.

## How to adopt this pattern

To adopt this pattern:

1. **Start with methodology.** Write the scoring rules in code.
2. **Add signing.** Generate key pair, sign every measurement.
3. **Add content-addressing.** Hash every artifact.
4. **Add witnessing.** Anchor in external systems.
5. **Add verifier.** Build a public, browser-based verifier.
6. **Add corrections.** Make the corrections feed machine-derived.

The pattern is incremental. You can build each component in turn.

## What this pattern enables

The pattern enables:

1. **Trust without marketing.** Verifiability creates trust.
2. **Independence without isolation.** Open methodology + signed receipts.
3. **Honesty without exposure.** Corrections feed is operational.
4. **Longevity without lock-in.** Standards-based, open-source.

## What this pattern prevents

The pattern prevents:

1. **Hidden methodology.** Open code makes the methodology inspectable.
2. **Tampered receipts.** Signed and content-addressed.
3. **Quiet corrections.** Machine-derived corrections feed is public.
4. **Vendor lock-in.** Open-source and standards-based.

## The industry opportunity

The AI governance industry is growing fast. Most organisations are building:

- Dashboards (proprietary metrics)
- Vendor comparisons (proprietary scoring)
- "Trust scores" (proprietary methodology)
- Conformity marks (proprietary certification)

CSOAI's pattern is different: **the evidence is the product**. Not the dashboard, not the score, not the mark. The evidence.

Adopting this pattern would let the industry move from marketing claims to verifiable evidence.

## The bottom line

Open methodology. Signed receipts. Content-addressing. Independent witnessing. Public verifier. Machine-derived corrections. Six components. Adopting them would change the industry.
